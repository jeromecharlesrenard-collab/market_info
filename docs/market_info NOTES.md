### App Description \& Operation:

1. The website is a home page (index.html, "MARKET INFO") with an alphabetical list of pages. Volume\_Info.html is the first page, with the "SPY Volume" box.
2. Duplicate of the JCR Knowledge Bank site: same style (assets/kb\_style.css), return arrow, top arrow, expand buttons, and tools.
3. New page: VS Code task "KB: New page" (or tools/new\_page.py) creates the page from the template and adds it to the home page list.
4. Preview: main.py starts a local server that behaves like GitHub Pages (case-sensitive). CHECK SITE finds broken links/images.
5. Publish: commit and push; the live site updates in 1-2 minutes.

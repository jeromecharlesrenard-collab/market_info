# market_info
Market Info

A collection of market reference pages, published at
https://jeromecharlesrenard-collab.github.io/market_info/

- `index.html` - home page with an alphabetical list of all pages
- `html_pages/` - all pages except the home page; `Volume_Info.html` - SPY average volume by time of day and candle timeframe (EDT)
- `assets/kb_style.css` - shared style used by every page
- `templates/page_template.html` - starting point for new pages
- `tools/` - Python helpers to create pages, check links, and preview locally
